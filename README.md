

# Awesome

## 桌面应用 

- [Typora](https://typora.io/)  写Markdown

- [Utools](https://www.u-tools.cn/) 工具箱
- [Yaak](https://yaak.app)  以本地优先的方式处理的 API 客户端
- [Bruno](https://www.usebruno.com/) 基于 Git 原生 API 的客户端
- [postman](https://www.postman.com/)
- [apifox](https://apifox.com/)
- [LocalSend](https://localsend.org/) 局域网传文件 快速、私密、离线

## CLI工具

- [nvm-windows](https://docs.nvm-windows.com/install/installers) 管理node版本 V2版本用go和zig重写，windows平台
- [fnm](https://fnm.vercel.app/) 管理node版本，rust写的，跨平台
- [nrm](https://github.com/Pana/nrm) 管理npm包的源，NPM 注册表管理器，能够快速切换不同的注册表：npm、cnpm、nj、淘宝
- [taze](https://github.com/antfu-collective/taze) 检查项目的依赖版本,一款现代化的命令行工具，能够保持依赖库的最新版本。
- [pake](https://github.com/tw93/pake) 打包网页成一个桌面应用
- [degit](https://github.com/Rich-Harris/degit)可以克隆git仓库用

## 前端

- [React](https://react.dev) 
  - [allotment](https://github.com/johnwalley/allotment)一个用于可调整大小的分割视图的 React 组件
  - [react-split-pane](https://github.com/tomkp/react-split-pane)React 分窗组件
  - [react-grid-layout](https://github.com/react-grid-layout/react-grid-layout) 一种可拖动和调整大小的网格布局，具有响应式断点设置，适用于 React 环境。
  - [FlexLayout](https://github.com/antoniandre/splitpanes)布局管理  **leetcode同款**
- [Vue](https://cn.vuejs.org/)
  - [splitpanes](https://github.com/antoniandre/splitpanes) 一款适用于 Vue 3 和 2 框架的、可靠的、简单的、支持触摸操作的窗分割器/调整工具。
- [Svelte](https://svelte.dev/)
- [Solid](https://www.solidjs.com/)
- [Preact](https://preactjs.com/)
